## V4.0 live power revision
BYD SDK V1.0.5 section 6.8.4 documents getEnginePower() as signed integer kW [-100,300]. Read android.hardware.bydauto.engine.BYDAutoEngineDevice.getEnginePower through unmodified application Context; manifest requests only ENGINE_GET, no permission bypass. Optional call on existing 500ms worker while dashboard requested, not on UI thread. Fresh successful getter result <=1800 ms; reject out-of-range readings; retry failures with 30s cooldown, no retained value masquerading as fresh. Zero shown as SDK 0 (not proof of signal calibration). Negative value with observed moving speed labelled REGEN SDK; stationary or unavailable speed labelled SDK power, not inferred regen. If unavailable, separate BMS AVG estimate or dash. Observed peak positive/negative during movement is process-session only; source, last raw, age, error, peak in diagnostics. Getter availability, sign/scale and zero-stuck behavior require comparison with vehicle cluster; no guarantee of -40kW at same instant. Other existing requirements remain unchanged. Cloud APK previous error was missing private vault/token; preflight now lists missing config before Gradle. No APK publication until existing private inputs and signer configured. MPP separate automatic build continues. Version display V4.0 (not 4.0.1).
