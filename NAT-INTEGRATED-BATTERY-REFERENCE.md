# NAT V3.1 — Integrated Battery Frame
Reference: supplied 37.9 s video, at ~22 s shows a compact light-blue card with a 9% figure at the right of the native trip summary, above the control buttons; ~24 s shows 45% on a similar summary. This is a visual reference only; the original implementation is unknown.

- Primary: root ViewOverlay drawable in the native status panel, 160x80 dp nominal, 36 dp nominal digits; smaller 144x72 / 128x64 dp options. Prefer full replacement of the verified small SOC region; otherwise a free cell beside it. A small battery-shaped progress bar below the number. Use original ColorScheme for dark/light.
- Fallback: immediately adjacent to the status panel, never arbitrary map corners. No change to native layout size or touch handling. If no safe location or unique matching native data, preserve original display (which may still be small). Native view resource names are present in the supplied APK, not a confirmed runtime hierarchy. No actual guidance-state/route-ID hook; a preview that matches the heuristic may qualify. A multi-stop native SOC might refer to the next stop, not final destination; no independent value is substituted.
- Read live native text only: strict combined or split summary (distance, ETA, one signed SOC, optional duration/arrival label). Named panel/compact child recognition, ambiguity rejection. Never uses stale pre-Start values or current vehicle SOC as replacement. Global layout/text updates plus one-second refresh. If no native TextView exposes the needed text, the frame cannot appear. Guard native text/controls; map canvas features may not be exposed to View traversal.
- Tests: 48 placement + 32 reference-style integration parser/geometry + 53 summary + 17 signed SOC/bar + 15 theme = 165 pure JVM cases/scenarios. These are NOT Android UI tests or tests on BYD.
- CI: NAT V3.1 integrated candidate build, artifact NAT-V3.1-integrated-candidate-mpp. Patch compatible base APK with existing Morphe Desktop and same signing key. Never install as verified Final before parked test. If frame missing, collect screen and `adb logcat -d -s NatArrivalUi` (if ADB already available): Integrated frame: no verified summary / ambiguous summaries / no safe summary space / visible integrated or adjacent. No route names or values recorded by this added status log.
