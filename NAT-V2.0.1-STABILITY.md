# NAT V2.0.1 Stability candidate
Four compact controls when a safe verified map area exists: EV, Energy, Charging Plan, Clean. Panels default closed; only one at a time. Native controls and warnings take precedence over fixed dimensions. No fabricated stations, cost, energy or availability. Tariff must be entered. Energy = forecast Wh plus known minimum charging additions; observed energy covers plausible moving sample pairs only; not full trip or calibrated regen. Charging plan uses the forecast; no candidate station feed, so automatic station selection is not implemented. Search through native Maps; user confirms stop. Native hide uses exact evidence, not Back or route cancellation; no guarantee native pins disappear. Auto-hide NAT panels on fresh forecast / changed charge count (proxy, not exact Start/Add Stop hook). GPS opt-in, stops on missing speed, 60s parked or 36s stale, no new background service. Theme logs expected vs system and keeps existing Maps controller hooks; actual whole-map theme unresolved until vehicle testing. Battery sizes remain safe adaptive; known noninteractive positive icon can be excluded from collision check; negative warning retained. No new paid API or billing. No runtime simulation data. Test parked; build and verify.

Follow-up: known native next-leg SOC is labeled separately; never replace native value with a potentially unrelated final forecast. Final value is visible in Charging Plan. Theme refresh also requested when activity regains focus, not forced Android recreation. Toolbar refresh reuses recent route verification. Explicit EV hide can be used when Maps exposes it; generic close still requires ownership and EV evidence.

## Live Energy / native station display extension
Current SOC mini card from fresh BYD samples, suppressed if native current-battery label is found; remaining energy mini card visible only while Energy panel open. Both yield to protected native controls and arrival overlay. Energy panel adds average battery power, observed net, positive energy changes while moving (not verified regen), odometer-covered consumption, forecast consumption and user tariff. No raw motor current/voltage scaling guesses; 5–30s sample pairs, moving both ends, 250kW plausibility threshold, missing values shown as —. No invented charger records or availability; Maps renders its own native results and details. Charging forecast includes power/distance if present. Native results may not expose every field. No new network calls. Existing manual calculators are separate, explicitly user estimates. Tests use fixtures only.
