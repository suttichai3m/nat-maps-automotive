# V3.7 Favorite Destinations — isolated feature candidate

Based on V3.6. Smart EV first entry; full-map long-press Split shortcut when visible. Eight local slots: home/work (unset), BKK, DMK, Pattaya, Hua Hin and two custom slots. Rename, edit, clear; address/name/coordinates accepted. Stored locally, never logged. Confirmation opens standard Google Maps directions URL without auto-start, pinned to this app; geo search fallback only if the directions intent cannot be resolved/launched. Existing native Maps decides actual route. If the installed patched Maps does not support the intent, show unavailable; no browser fallback. Route can change only after user chooses to open the destination. No changes to split geometry, telemetry, TPMS or other V3.7 requirements. CI adds pure URI tests; Android APK, native intent handling and vehicle acceptance pending.
