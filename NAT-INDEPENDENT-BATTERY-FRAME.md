# NAT V3.1 — Independent Arrival Battery Frame (test candidate)
SUPERSEDED by NAT-INTEGRATED-BATTERY-REFERENCE.md. Historical design only.
Base: supplied map-original ZIP, plus previous navigation battery source candidate. The overlay is independent of the native TextView's size. Full frame 200 × 120 dp, 40 dp nominal digits; fallback widths 184/168 dp (scaled proportionally). Up to 12 candidate positions per size, keep stable valid position; avoid visible native text/controls and never overlap the anchor. Native arrival display is preserved when a verified summary or safe slot cannot be found. No fake SOC, no cache, no changes to prediction/GPS/theme implementation.

Input: single native distance/ETA/arrival-SOC summary; expanded separators, duration, ETA labels, battery icon, signed SOC. Split input must be in an observed status-panel resource subtree, or explicitly labelled arrival SOC in a small nearby subtree. Ambiguity clears frame. The resource strings were observed in supplied APK, but actual in-car view hierarchy and route identity/active navigation are not verified. This is a heuristic, not an authoritative navigation-state hook. Before-Start UI could also satisfy the heuristic. The overlay may hide if no matching data/safe slot; map-rendered symbols may not appear in the Android View tree. No guarantee of always-visible on vehicle. Logging uses existing NatArrivalUi tag, records status and size only, not routes or percentages. Existing 1 s refresh, global layout and text updates retained.

Tests: 53 parser cases, 48 pure geometry scenarios, 17 signed SOC/bar tests, 15 theme schedule tests = 133. No Android SDK/Morphe dependencies here: not Android-compiled, not APK, no actual car test. CI runs all four scripts before Gradle. Apply complete patch to clean original map-original branch; incremental patch only to exact previous source version. Do not apply both. Build workflow NAT V3.1 integrated candidate build; artifact NAT-V3.1-integrated-candidate-mpp. Use existing Morphe Desktop and compatible base APK/signing key. Keep previous working APK. Test while parked: route preview, Start, actual arrival SOC, theme switch, stop; confirm overlay does not obscure important map content. If missing, collect full screen and existing problem report/log NatArrivalUi: Independent frame: no verified summary / ambiguous summaries / no safe space / visible single or split. Do not merge to main until verified.
