# Build 14 — native summary experiment
Uses a fixed 220 x 124 dp ReplacementSpan in recognized native route summaries, with 50 dp SOC and battery icon. No floating card placement or six-second expiry on this path. Native parent may clip or reject the span; actual navigation lifecycle and missing-data placeholder are not implemented. Manual day/night refresh receives a copied configuration with selected uiMode; native map response remains unverified. No GPS/MicroG changes. Existing pure Java tests cover parsers, old placement/continuity helpers and theme schedule, not Android rendering. Android compilation and vehicle tests pending.
