# NAT Cloud APK Builder (private output)
The source repository is public. Never commit APK inputs, keystores, credentials or options with secrets. Create a separate PRIVATE repository (for example nat-apk-vault), initialize it, and create release tag nat-inputs with original.apk (legally obtained, unpatched Google Maps Automotive 26.10.120003.E) and reviewed options.json from Morphe Desktop. This workflow uploads only to that private repository, not public Actions artifacts. Use only content you have permission to store.
Create environment nat-cloud-signing in source repo Settings > Environments, restrict deployment branches to map-original, and optionally require approval. Create a fine-grained PAT scoped only to the private vault, Contents read/write and Metadata read; store as environment secret NAT_VAULT_TOKEN. Variables in environment: NAT_VAULT_REPO (owner/repo), NAT_ORIGINAL_SHA256 (64 hex), NAT_SIGNER_SHA256 (certificate digest from apksigner verify --print-certs of known good installed APK), NAT_KEY_ALIAS (Morphe by default). Secrets: NAT_KEYSTORE_B64 (base64 existing key file), NAT_KEYSTORE_PASSWORD (if nonempty), NAT_KEY_PASSWORD (if custom; default Morphe). Existing MORPHE_PACKAGES_TOKEN can be reused. Do not paste private key into chat or commit it. Export existing keystore from Morphe Desktop Settings > Signing > Export; never generate a new one for an update. On Mac, shasum -a 256 original.apk; base64 -i morphe.keystore | pbcopy. Paste directly into GitHub secret, clear clipboard afterwards. Obtain signer digest with Android SDK apksigner. Use existing patch selections; if missing, run mode options to generate defaults for review, not a guarantee of matching desktop settings. Attach reviewed options.json to nat-inputs release. The CLI jar is pinned to 2.4.0 and SHA256 verified. No force or continue-on-error flags.
Manual workflow dispatch requires workflow file on default branch (main). If not visible, copy only .github/workflows/nat-cloud-apk.yml to main; do not merge app source. Run on map-original, version label, mode build. Download APK from private vault Releases in Safari > Files. No laptop required after one-time input/key setup. Do not install on iOS. No vehicle validation implied. GitHub Actions/storage quotas apply. The pipeline needs first end-to-end run with real inputs to validate compatibility, patch selection, signing and output. No secrets have been created by this commit.
